Bloom Nail Studio

A bright, gallery-first nail studio site built to give nail art a real browsable home instead of a scrolling Instagram feed.

View live site → Back to portfolio

Problem

Nail studios sell almost entirely on visuals — nail art is inherently shareable — but that usually means the "portfolio" lives only on Instagram, where older work scrolls out of reach and there's no way to browse by style. A new client scrolling a feed can't easily compare a French set against a chrome set against hand-painted art side by side, and there's rarely a clear price list attached to any of it.

Approach

Built around alternating full-bleed color panels (coral, mint, sunshine yellow) and full-bleed photo breaks in place of the boxed sections used elsewhere in the portfolio — a bright, editorial rhythm matched to what the business actually sells. The service menu is genuinely pill/chip-shaped this time, grouped by category (manicures, pedicures, add-ons) with color-coded price pills, not a card grid with a chip aesthetic bolted on. The gallery is a bento grid — one large featured tile plus varied smaller tiles, closer to a curated wall than a uniform grid — still click-to-expand, since a lightbox is still the fastest way to see one nail set at full size. Reviews sit in tilted, Polaroid-style cards instead of a straight card row, reinforcing the playful tone through layout, not just color.

Tech Stack

Same offline-first foundation as the rest of the portfolio: plain HTML5, CSS3, vanilla JavaScript, single self-contained file, zero external dependencies, no build step. The bento grid uses CSS Grid column/row spans rather than a masonry column layout, and the lightbox pulls its image straight from each tile's computed background-image instead of a separate data attribute.

Result

Same honesty rule as the rest of the portfolio: no real client means no real booking or traffic numbers, so none are claimed.

Verified in-browser: zero external network requests, zero console errors, working bento gallery lightbox and mobile nav at phone widths. The meaningful result to point to in a pitch is the range across all four spec projects — one offline-first foundation, four structurally different builds, not one template reskinned four times.
