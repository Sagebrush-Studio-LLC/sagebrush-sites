Concept Project · Case Study

Haven Hair Studio

A modern, minimalist hair salon site built to answer the two questions that actually get a new client to book: what does this cost, and what does the work look like?

View live site → Back to portfolio

Problem

Most independent hair salons fall into one of two traps online: a slow, generic template site that takes forever to load on a phone, or no real site at all — just an Instagram grid and a Linktree. Either way, a prospective client can't quickly answer the two questions that actually get them to book: what does this cost, and what does the work actually look like?

Approach

Built a single-page site around answering both questions in under one scroll: icon-led service categories up top so a visitor immediately sees the range (cuts, color, styling, treatments) before hitting a plain, priced list underneath (no "call for pricing"), a masonry-style photo gallery with a click-to-expand lightbox so the actual hair work is the visual centerpiece — varied tile heights instead of a uniform grid, closer to how a stylist would actually lay out a portfolio, a small team strip so "who's cutting my hair" has an answer, a minimalist neutral palette (cream, blush, charcoal) that keeps the photography the focal point, and a mobile-first layout with a working hamburger menu, since salon browsing overwhelmingly happens on a phone between appointments.

Tech Stack

Plain HTML5, CSS3 (custom properties, Grid/Flexbox, aspect-ratio), and vanilla JavaScript — no framework, no build step, single self-contained file. JS handles the gallery lightbox (click to open, Escape or click-outside to close) and the mobile nav toggle. The contact form submits via mailto: rather than a backend; in a real build this gets replaced with whichever booking platform the client already uses.

HTML5CSS3Vanilla JSZero dependenciesNo build step

Result

No real client, so no real traffic or booking data to report — inventing a conversion number here would be exactly the kind of unverifiable claim to avoid.

What's verifiable: the site opens via file:// with zero external network requests and zero console errors, checked directly in-browser. The mobile nav, gallery lightbox, and service menu all work as built. That's the honest, checkable version of "it works."
